# Мой курс — цели, часы и контрольные точки

[Открыть дашборд](https://smit1980.github.io/moy-kurs-dashboard/)

Просмотр плана открыт всем. Кнопка **Редактировать** запрашивает пароль; его проверяет сервер. Пароля в этом репозитории нет. Перезагрузка страницы блокирует редактирование.

## Индикаторы

| Цвет | Значение |
| --- | --- |
| Серый | Сегодня или будущая дата без факта |
| Синий | Есть факт, работа продолжается |
| Оранжевый | Дата прошла, факт не отмечен |
| Красный | Дата прошла, факт меньше плана |
| Зелёный | План выполнен |

Пустое поле и **0** различаются. Кольцо часов показывает факт/план, кольцо цели — результат или выполненные контрольные точки. Справка с примерами: кнопка **Помощь**. Даты оцениваются по Москве.

## Хранение и выпуск

GitHub Pages публикует HTML/CSS/JS. Общий план хранится в D1 через HTTPS API из config.js. Запись защищена серверной сессией, CSRF, проверкой Origin и ограничением входа. Ревизии защищают от одновременной перезаписи.

Workflow публикует только index.html, styles.css, app.js, indicators.js, config.js и .nojekyll. Аудиозаписи, документы, учётные данные и SQLite не включены. API возвращает открытый план по решению владельца.

Часы и точки отмечаются вручную. Автоматической двусторонней синхронизации с календарями здесь нет.
